# Slides

Two toolchains live here during the rebuild. **Beamer is current; Slidev is legacy.**

| | Path | Status |
|---|---|---|
| **Beamer** | `beamer/NN-short-name.tex` | Current. Chapter 1 built. Chapters gain a `.tex` as each is rebuilt |
| **Slidev** | `NN-short-name.md` | Legacy. Chapters 2–19 still live here until rebuilt, and their PDFs in `exports/` are the last presentable versions |

Slidev was adopted on trial 2026-08-19 and reversed 2026-08-20. Both spikes passed and no reversal
trigger fired; the reversal came from a six-way format comparison that produced better reasons than
the triggers anticipated. Evidence in `format-trial/README.md`, decision in `../DECISIONS.md`.

## Beamer — the current path

### One-time setup

The theme lives outside this repository, at `~/Desktop/Claude/beamer-uhtraining`. Run its
installer once so `\usetheme{UHTraining}` resolves from any directory:

```
cd ~/Desktop/Claude/beamer-uhtraining && ./install.sh
kpsewhich beamerthemeUHTraining.sty          # should print a path under ~/texmf
```

**xelatex or lualatex only.** pdflatex is not supported — the theme uses real Times New Roman
through `fontspec`, and TeX Gyre Termes Math so the equations match the body text.

### Build

```
cd slides/beamer && ./build.sh 01-substrate
```

It gates on three things and stops on any of them:

1. **The frame check** (`check-frames.py`) — every frame carries a footer, every cited key resolves
   and is tagged `[V]`.
2. **LaTeX errors.**
3. **Overfull vboxes.** An overfull vbox is precisely a frame whose content runs into the chevron
   footline. This is the check that earns its keep: it found seventeen such frames on Chapter 1's
   first build, each of which would otherwise have had to be caught by eye, one page at a time.

### Files

| File | What it is |
|---|---|
| `01-substrate.tex` | the deck |
| `preamble.tex` | shared: the four number colours, diagram styles, the `\animatable` marker |
| `uhcite.sty` | `\citesource{key}` and `\provenance{...}` — the footer machinery |
| `uhslot.sty` | `\slotF` / `\slotW` / `\slotH` — reserved animation boxes |
| `uh-sources.tex` | **generated** from `../../references.md`; never edit it |
| `check-frames.py` | the frame gate |
| `build.sh` | build and gate |

### Rules

- **Citation keys are never hand-typed.** `\citesource{vaswani2017}` resolves against
  `uh-sources.tex`, regenerated by `../scripts/gen-sources-tex.mjs` on every build.
- **A frame with no external source carries `\provenance{...}`**, from the fixed vocabulary:
  `definition`, `derived`, `computed`, `observation`, `schematic`, `none`. An unrecognised word
  prints as a visible error, exactly like a bad key.
- **Size figures by height, not width.** The theme leaves about 58 mm of content once the logo
  band, a two-line frame title and the footline are taken out, and the footer takes 6 mm of that.
  `width=0.93\linewidth` on a 2.7:1 figure is already over.
- **Speaker notes go in `\note{}`.** They are not rendered by default; they are the source of truth
  for what is said rather than shown.
- **Export and commit the PDF whenever a chapter is finished.**

### Known limits, measured

- Beamer's `\inserttotalframenumber` needs a second pass, which is why `build.sh` runs xelatex twice.
- The theme's chrome is heavy, which is why the animation slots are letterbox. See
  `../curriculum/ch01-animation-slots.md` for the arithmetic and the lever if taller slots are wanted.

Still builds. Chapters 2–19 have not been rebuilt yet and their committed PDFs in `exports/` remain
the last presentable versions of those chapters.

```
npm run dev                    # live preview
npm run export                 # PDF, then version-stamps it for the review round trip
npm run check:cites            # fails on a [U] source, or a footerless slide in .footer-check
npm run check:cites:selftest    # proves the check still trips on a known-bad fixture
```

**Do not port new work to this path.** Fix a Slidev deck only if a chapter has to be delivered
before it is rebuilt.

### Two findings recorded here so they are not rediscovered

**Math inside a one-line raw `<div>` does not render.** CommonMark swallows everything to the next
blank line, so `$…$` never reaches KaTeX. The build succeeds and the slide is wrong, which is the
dangerous combination. Fix: blank lines inside every cell.

**Slidev renders Mermaid inside a shadow root.** No stylesheet in this project can reach the SVG,
and the `{scale: n}` fence option sets height only. A long left-to-right chain saturates the slide
width at its natural size, so the lever for a diagram that looks small is fewer nodes per row, not
a larger scale. This cost three Chapter 1 diagrams a restructure and is one reason the toolchain
moved.

## PDF review round trip

`npm run export` stamps each PDF's metadata with a hash of its markdown source and the slide count,
so annotations made on a PDF can later be resolved to exact source lines and a stale PDF is
detectable rather than silently mis-mapped. Workflow and scripts: `../curriculum/pdf-review-workflow.md`
and `scripts/pdf-review/`.

**The Beamer path has no equivalent yet.** Chapter 1's review round trip used the Slidev export.
Porting the stamper is straightforward — the metadata write is `mutool`, not Slidev — and it is not
done.
